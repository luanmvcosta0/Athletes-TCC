# 🏀 Athletes — TCC

Protótipo de interface de login desenvolvido como parte inicial do meu Trabalho de Conclusão de Curso (TCC). O **Athletes** seria uma plataforma voltada para atletas e times esportivos, e este repositório contém a primeira tela do projeto: a página de autenticação.

> ⚠️ **Status:** projeto arquivado (agosto/2023). Foi um dos meus primeiros contatos com desenvolvimento front-end, mantido aqui como registro da minha evolução como desenvolvedor.

## ✨ Sobre a tela

A página de login conta com:

- Layout dividido (split screen), com chamada e ilustração animada de um jogador de basquete em SVG à esquerda e o formulário à direita
- Card de login com campos de **e-mail** e **senha**
- Botões de login social (Facebook e Google) — apenas visual
- Links de "Esqueceu a senha?" e cadastro — apenas visual

Todo o estilo foi construído com **CSS puro**, sem frameworks, como exercício de aprendizado de layout, posicionamento e estilização.

## 🛠️ Tecnologias

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout
- **SVG animado** — ilustração do jogador de basquete

## 🚀 Como rodar

Não há dependências, é um projeto 100% estático. HTML e CSS puro.

1. Clone o repositório:

```bash
git clone https://github.com/luanmvcosta0/Athletes-TCC.git
cd Athletes-TCC
```

2. Abra o `index.html` diretamente no navegador, **ou** use a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) do VS Code:

```
http://localhost:5500
```
